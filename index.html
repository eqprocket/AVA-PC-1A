Perguntas Frequentes

O cliente precisa criar login para conversar no Chat Web do site?

Não. O visitante apenas abre o chat, informa o nome se solicitado e inicia a conversa normalmente. O atendimento entra diretamente na fila configurada da sua equipe.

A Inteligência Artificial envia mensagens automaticamente?

Não. O copiloto de IA funciona de forma puramente assistida: ele gera rascunhos, resumos ou sugestões que precisam ser revisados e confirmados pelo atendente antes do envio.

É possível utilizar o AtendaFlow no celular?

Sim! Além do painel Web para computadores, disponibilizamos um aplicativo nativo para Android para que a equipe possa responder atendimentos em movimento.

Posso integrar o AtendaFlow com outros sistemas?

Sim. A plataforma possui API REST autenticada, suporte a Webhooks assinados e integração pronta com ferramentas como GLPI, Prometheus e Grafana.
